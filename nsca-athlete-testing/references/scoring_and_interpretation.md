# Scoring And Interpretation

## Score Types

Use the score type that answers the question:
- Raw score: direct test result
- Relative score: normalized to body mass or another variable
- Change score: current score minus previous score
- Percent change: change relative to baseline
- Rank: team order
- z-score: distance from group mean in standard deviations
- T-score: standardized score with mean 50 and SD 10

## Directionality

Some tests are better when higher, others when lower.

Higher is better:
- Jump height
- Force
- Load lifted
- Distance jumped
- Repetitions

Lower is better:
- Sprint time
- COD test time
- Error counts

Always set direction before ranking or standardizing.

## Relative Strength

Relative strength = lifted load / body mass.

Use for comparing athletes of different body sizes, while noting that simple ratio scaling has limitations.

## Interpreting Change

A change is more meaningful when:
- Testing conditions were standardized
- The change exceeds normal measurement noise
- The athlete was familiar with the test
- It aligns with training history and other data

## Athlete Profile

Profile should include:
- Strengths
- Limiters
- Training priorities
- Monitoring recommendations
- Context notes

Avoid reducing an athlete to one score.

## Norms And Comparison Groups

Use comparison data only when relevant to:
- Age
- Sex if applicable
- Sport
- Position/event
- Competitive level
- Testing protocol

If no relevant norms exist, use team, squad, or individual longitudinal data.

## Practical Interpretation

Translate scores into actions:
- Improve maximal strength
- Improve rapid force production
- Improve deceleration or COD mechanics
- Improve aerobic base
- Maintain current quality
- Re-test after a specific training block

## Reporting Caveats

Mention:
- Missing data
- Small sample size
- Hand timing
- Different surfaces
- Incomplete warm-up standardization
- Recent fatigue or injury
- Unclear test validity for the sport

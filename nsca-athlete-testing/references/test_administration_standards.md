# Test Administration Standards

## Before Testing

Confirm:
- Purpose and selected tests
- Athlete consent or organizational process
- Health restrictions and injury status
- Equipment availability and calibration
- Staff roles
- Testing order
- Warm-up
- Recording system

## Test Order

General order:
1. Nonfatiguing measurements: height, body mass, mobility
2. Skill or technique screens
3. Power tests: jumps, throws
4. Speed tests
5. Agility or COD tests
6. Max strength tests
7. Muscular endurance
8. Anaerobic capacity
9. Aerobic capacity

Adjust order when the main purpose requires a specific test to be freshest.

## Standardization Variables

Control:
- Time of day
- Prior training load
- Nutrition/hydration when relevant
- Footwear
- Surface
- Warm-up duration
- Instructions
- Trial number
- Rest between trials
- Tester
- Timing method
- Equipment settings

## Personnel

Assign:
- Lead tester
- Timer/operator
- Recorder
- Spotters for maximal strength tests
- Safety monitor for large groups

## Warm-Up

Use a standardized warm-up:
- General temperature-raising movement
- Mobility related to test demands
- Dynamic movement
- Submaximal practice trials
- Test-specific build-up

## Trial Rules

Define:
- Number of attempts
- Rest intervals
- Best score, average score, or all trials
- Invalid trial criteria
- Retest rules

## Safety Stop Criteria

Stop testing and refer when:
- Sharp pain
- Chest pain
- Dizziness or faintness
- Neurological symptoms
- Abnormal shortness of breath
- Technique failure under maximal load
- Athlete cannot follow instructions

## Documentation

Record:
- Date and time
- Athlete ID
- Body mass if relevant
- Test conditions
- Equipment
- Raw scores
- Notes on invalid trials
- Tester initials
- Athlete comments

# Test Selection Principles

## Start With The Decision

Choose tests only when the result will influence:
- Program design
- Athlete profiling
- Goal setting
- Progress evaluation
- Readiness or fatigue monitoring
- Talent identification
- Return-to-training communication with the allied health team

## Validity

A test should measure the quality it claims to measure. Consider:
- Construct validity: does it represent the intended quality?
- Face validity: does it appear meaningful to athletes and coaches?
- Content validity: does it cover the relevant performance domain?
- Criterion validity: does it relate to a useful standard or outcome?

## Reliability

A test should produce consistent results when conditions are consistent. Improve reliability by standardizing:
- Warm-up
- Instructions
- Equipment
- Surface
- Time of day
- Trial number
- Rest intervals
- Tester
- Scoring method

## Practicality

Select tests that fit:
- Available equipment
- Staff skill
- Athlete skill
- Time
- Space
- Cost
- Safety
- Data management capacity

## Specificity

Tests should align with sport demands and training goals. Avoid batteries that measure everything but answer nothing.

## Sensitivity

A test should detect meaningful change. Be cautious when:
- The expected change is smaller than measurement error
- Testing conditions vary
- The athlete is inexperienced with the test
- Motivation is inconsistent

## Safety

Avoid or modify tests when:
- The athlete lacks technique competence
- Medical restrictions exist
- Fatigue makes the test risky
- The test requires equipment or personnel you do not have

## Test Battery Rule

A strong test battery is:
- Short enough to run consistently
- Specific enough to inform training
- Reliable enough to compare over time
- Safe enough for the athlete group
- Practical enough to repeat
